## Живая проверка после разрешения записи экрана — 2026-10-30

- Захват области запущен через меню; зафиксирован реальный экран без окна настроек.
- Добавлены стрелка и русский текст через поле редактора; Enter завершил ввод.
- Область изменена с 1440×700 до 1470×730, аннотации сохранили положение относительно изображения.
- NSSavePanel открылся, отмена вернула редактор с правками; повторный вызов через ⌘S сработал.
- PNG сохранён в `build/qa-region.png`. Файл открыт и проверен: 1470×730, правильная ориентация, стрелка и текст присутствуют, рамки и панель отсутствуют.
- Полный захват через меню открыл редактор с размером 3024×1964. ⌘C завершило сеанс через успешную запись в буфер.
- Вставку в Preview подтвердить не удалось: инструмент управления macOS дважды вернул SCStreamError -3811 при чтении окна Preview. Это ограничение проверки, а не установленная ошибка Screenshot.
- Синтетическое ⌥⇧F через инструмент управления не вызвало захват; физическое глобальное сочетание подтверждалось пользователем на прототипе. Финальную проверку физической клавиши следует выполнить вручную.

## Ручные сценарии

- [x] Выделить область → стрелка → текст → изменить границы → сохранить PNG и проверить файл.
- [ ] Вставить скопированный снимок в Preview/чат.
- [x] Полный экран под курсором → проверить размер 3024×1964 → ⌘C → редактор закрыт.
- [ ] Полный экран → правки → сохранить PNG → проверить файл.
- [ ] Проверить клавиши, текст, Esc и сохранение поверх чужого полноэкранного приложения.
- [ ] При вводе текста: русский текст, Enter/Shift+Enter, ⌘C/⌘V, редактирование двойным нажатием.
- [ ] Все инструменты; выбор, цвет, размер, удаление; отмена одного жеста и повтор.
- [ ] ⌘Z / Esc / копирование во время перетаскивания не вызывают сбоя.
- [x] Отменить NSSavePanel — правки остаются.
- [ ] Сохранить в недоступную папку — правки остаются.
- [ ] Назначить одинаковые сочетания обоим действиям — ошибка, прежнее сочетание работает.
- [ ] Отключить разрешение записи экрана — понятное сообщение, редактор не появляется.
- [ ] Переключить Space или отключить монитор во время захвата — панели исчезают и не возвращаются.
- [ ] Два монитора с разным масштабом; второй слева/выше; полное изображение захватывается под курсором.
- [ ] Автозапуск включается и выключается из постоянного расположения приложения.

Непроверенные сценарии не считаются пройденными по результату компиляции или тестов модели.
