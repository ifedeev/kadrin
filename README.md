# Kadrin

Нативный скриншотер для Apple Silicon, macOS 26 и новее. Swift + AppKit + ScreenCaptureKit; внешних зависимостей и сетевых запросов нет.

## Запуск

Готовая сборка: `build/Kadrin.app`. Откройте её в Finder. Приложение находится в строке меню, значка в Dock нет. Повторное открытие приложения показывает настройки.

В настройках нажмите **«Разрешить…»** и включите Kadrin в **Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного аудио**. При необходимости перезапустите приложение. Разрешение Accessibility для глобальных сочетаний не требуется.

Перед включением автозапуска перенесите приложение в постоянное место (например, `~/Applications`), запустите оттуда и включите переключатель. Для переноса уже настроенного приложения сначала выключите автозапуск, завершите приложение, перенесите и включите снова. macOS может потребовать подтвердить объект входа.

Это локальная ad-hoc подписанная сборка, без Developer ID и нотариального заверения для публичного распространения. Пересборка может потребовать повторного разрешения записи экрана. Не держите одновременно запущенными несколько копий.

## Название и оформление

Kadrin («Кадрин») — от слова «кадр». Утверждённый знак — два смещённых плоских кадра. Цветная иконка используется для приложения и настроек; монохромный шаблон в строке меню адаптируется к теме macOS.

Панель рядом с выделением использует нативное стекло AppKit. Нижний ряд показывает параметры текущего инструмента; выбранные инструмент и цвет отмечены явно.

Внутренние имена Swift-модулей и bundle identifier `com.saidazam.screenshot` сохранены для совместимости с настройками.

## Работа

| Действие | Управление |
|---|---|
| Область на любом мониторе | ⌥⇧S, затем выделить мышью |
| Весь монитор под курсором | ⌥⇧F |
| Изменить границы | Перетащить белые маркеры |
| Переместить область, сохранив рисунки на месте | Пробел + перетаскивание |
| Выбрать объект | Инструмент «Выбор и перемещение», затем нажать объект |
| Изменить размер объекта | Перетащить угловой маркер системного акцентного цвета |
| Исправить текст | Двойное нажатие на текст в режиме выбора |
| Завершить ввод текста | Enter; Shift+Enter — новая строка |
| Удалить выбранный объект | Delete |
| Отменить / повторить правку | ⌘Z / ⇧⌘Z |
| Скопировать изображение | ⌘C или кнопка панели |
| Сохранить PNG | ⌘S или кнопка панели |
| Отменить захват | Esc |

Во время ввода текста ⌘C/⌘V работают с текстом. Кнопка копирования на панели сначала завершает ввод и копирует весь снимок.

Инструменты: карандаш, линия, стрелка, прямоугольник, эллипс, маркер, текст, номера шагов, размытие и непрозрачное скрытие. Для изменения цвета, толщины или размера существующего объекта сначала выберите его. Скрытие всегда непрозрачно и рисуется последним, поверх других объектов.

**Размытие:** выберите кнопку «Размытие» (капля) и растяните прямоугольник по снимку. Через «Выбор и перемещение» область можно двигать, менять её размер и удалять; ⌘Z отменяет действие. Размывается исходный снимок, а подписи и стрелки остаются поверх. Для полного закрытия чувствительного фрагмента используйте непрозрачное скрытие.

Область не пересекает границу мониторов. Рисунки за границами области сохраняются в текущем сеансе и снова видны при расширении. При экспорте всё за границами обрезается. История отмены содержит до 100 изменений текущего сеанса и очищается при его закрытии.

Смена рабочего стола или конфигурации экранов отменяет захват. Ошибка сохранения и отмена диалога оставляют редактор открытым. Защищённое macOS/DRM содержимое может отсутствовать на снимке.

## Сборка и тесты

Нужен Xcode 26 с macOS SDK 26 или новее. Проверки Core Image требуют доступа к графическому рендереру macOS; ограниченная песочница агента может не предоставлять его. Перед пересборкой завершите запущенный Kadrin; после сборки откройте приложение заново.

```bash
./scripts/swift.sh test
./scripts/build-app.sh
```

Открыть `Package.swift` в Xcode можно для навигации и отладки. Для обычного использования запускайте `.app`, созданный скриптом: он содержит стабильный bundle identifier и настройки фонового приложения.

## Устройство

- `ScreenshotCore`: геометрия, аннотации, история правок, рендеринг, PNG и защита жизненного цикла захвата.
- `Screenshot`: окна AppKit, ScreenCaptureKit, горячие клавиши, редактор и настройки.
- `Tests`: проверки координат Retina, истории, преобразований объектов, ориентации и непрозрачного скрытия при экспорте.

Чек-лист ручной проверки и фактические результаты — в `docs/TESTING.md`.
